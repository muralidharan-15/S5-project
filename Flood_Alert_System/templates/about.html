SYSTEM ARCHITECTURE & OVERVIEW

AI-Powered Real-Time Flood Alert & Weather Intelligence

Autonomous meteorological data pipeline paired with Random Forest Machine Learning threat prediction.

🔄 End-to-End System Pipeline

🌐
1. Open-Meteo REST API

Retrieves live satellite streams, precipitation, humidity, wind & pressure.

⚙️
2. Feature Processing

Calculates rolling 1-day, 3-day, 7-day accumulated rain & 7-day average rate.

🧠
3. Random Forest ML

100 decision trees evaluate non-linear flood probability (99.88% accuracy).

🛡️
4. Threat Classification

Classifies threat level into LOW, MODERATE, HIGH + dynamic advisories.

💻 Technology Stack
  • Core Backend: Python 3.10+, Flask WSGI Framework
  • Machine Learning: Scikit-Learn (Random Forest Classifier)
  • Data Stream: Open-Meteo REST API (Live Weather & Satellite)
  • Data Wrangling: Pandas, NumPy, Joblib Serialization
  • Frontend UI: HTML5, Vanilla CSS Design System, Bootstrap 5, Chart.js v4.4
🎯 Model Validation & Accuracy

The Random Forest classifier was trained on multi-year regional precipitation and flood records.

Evaluated Test Accuracy 99.88% Score

Feature Vector: Rainfall_1Day, Rainfall_3Day, Rainfall_7Day, Rainfall_7Day_Avg.
